Engine Architecture

Built to Defeat Evasive Server Code

Attackers don't follow schema definitions. `mcp-behave` operates at the libc layer to capture the reality of what executes.

Zero-Root Libc Interposition

No `ptrace` or root privileges required. Injects custom interposition libraries via macOS `DYLD_INSERT_LIBRARIES` and Linux `LD_PRELOAD` with automatic `strace` fallback.

Symlink & Obfuscation Defense

Canonicalizes all paths via `realpath()` and inspects live file descriptors (`fcntl F_GETPATH` on macOS, `/proc/self/fd` on Linux) to prevent symlink traversal cloaking.

Long-Path Truncation Detection

4096-byte trace buffers with explicit ! TRUNCATED markers flag and escalate buffer-overflow and path-padding evasions straight to HIGH severity.

Full Socket & Datagram Interception

Interposes `connect`, `sendto`, `sendmsg`, and `sendmmsg` across IPv4, IPv6, UDP, abstract UNIX sockets (`@containerd-control`), and Docker control sockets.

Expanded Secret Targets

Detects unauthorized access to `.gnupg`, `.npmrc`, `.pypirc`, `.git-credentials`, AWS, Azure, Google Cloud tokens, and Chrome/Firefox/Safari browser credential databases.

Behavioral CI Lockfiles

Pin server behavior in `mcp-behave.lock`. Run `mcp-behave check` in CI to fail builds only on undeclared behavioral regressions, with zero false alerts on approved baselines.

The Inspection Loop

How `mcp-behave` Uncovers Lies

01

1. Interposed Spawn

The target MCP server is launched with a dynamically interposed C library attached to its address space. Every socket, open call, and process execution is intercepted with microseconds overhead.

02

2. Multi-Round Probing

`mcp-behave` queries tool schemas and sends varied, realistic synthetic arguments over multiple rounds (--probe-rounds N), preventing static canary avoidance.

03

3. Contract Audit & Diff

Observed kernel actions are audited against tool descriptions, `.mcpbehaverc.json` policies, and the full 62-rule MCP-audit catalog, exporting to SARIF v2.1.0 or failing your CI pipeline.

CI / CD Gating

Fail PRs on Behavioral Drift

Integrate `mcp-behave` into GitHub Actions or GitLab CI. Export SARIF v2.1.0 alerts straight into GitHub Security Code Scanning and block pull requests when undeclared scopes creep into releases.

  • --fail-on HIGH  # exit code 1 on scope violations
  • --sarif-output results.sarif
  • --config .mcpbehaverc.json  # policy overrides
# .github/workflows/audit.yml
name: Behavioral Security Audit
on: [push, pull_request]

jobs:
  mcp-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run mcp-behave
        run: |
          pip install mcp-behave
          mcp-behave audit \
            --fail-on HIGH \
            --sarif-output results.sarif \
            -- python server.py
      - name: Upload SARIF
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: results.sarif
