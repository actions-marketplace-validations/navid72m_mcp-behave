## Community

Please read the [Code of Conduct](CODE_OF_CONDUCT.md) before participating.

- **Contributing:** See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, tests, and pull-request guidance.
- **Questions and support:** See [SUPPORT.md](SUPPORT.md) before opening an issue.
- **Security issues:** Report vulnerabilities privately using the process in [SECURITY.md](SECURITY.md). Please do not disclose vulnerabilities in public issues or pull requests.
